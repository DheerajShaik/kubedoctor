# Changelog

## v0.2.0

- Capture minimized evidence, replay it offline at the captured evaluation time, and compare findings across two observations.
- Explore related resources and findings in text, JSON or a standalone HTML report. Coverage and identity determine whether a recovery can be verified.
- Collect opt-in historical Prometheus evidence and display bounded, conditional resource sizing advice with configured Grafana navigation.
- Inspect additional stateful, batch, autoscaling, resource-policy and network evidence. Scoped MCP tools support investigation and authorized artifacts.
- See [migration and installation](docs/releases/v0.2.0/MIGRATION.md), [compatibility](docs/releases/v0.2.0/LAB.md) and [release evidence](docs/releases/v0.2.0/ACCEPTANCE.md).

## v0.1.0

- Added the kubectl plugin and direct CLI for deterministic namespace and cluster diagnosis, with terminal and versioned JSON reports.
- Added diagnostic checks for workload, configuration, storage, networking, disruption and resource symptoms with explicit coverage and confidence.
- Added a read-only stdio MCP adapter with context and namespace restrictions.
- Added example RBAC, compatibility fixtures, and reproducible build and validation instructions.
