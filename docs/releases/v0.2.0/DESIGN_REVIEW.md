# Independent release design review

This review treats observations, inference, and unmet validation as distinct evidence. It is an internal review and is independent of the external PR review gate.

| Risk | Required disposition | Acceptance evidence |
| --- | --- | --- |
| A missing finding is mistaken for recovery | Require strong cluster provenance, compatible scope and analyzer contracts, relevant evidence coverage and freshness, and matching resource continuity before resolution. Treat resource replacement, source loss, and changed rules explicitly. | Comparison fixtures with permission loss, removed APIs, unknown/stale/truncated evidence, narrower scope, replacement and evaluator mismatch. The live lab repairs a ConfigMap dependency while checking the same Deployment and Pod UIDs. |
| Pod churn hides a regression or inflates it | Retain object findings separately. Group workload state only through verified controller UID relationships and retain coverage and evidence for every occurrence. Provision stable finding identity by rule, primary resource and diagnosis discriminator. | Unit fixtures for separate same-rule occurrences and controller replacement. Replica churn within one Deployment must preserve workload identity. |
| A capture claims atomicity or applies today's clock during replay | Record collection interval, per-source read intervals, and fixed evaluation time. Let replay operate on normalized captured inputs with current provider access disabled. Bind analyzer compatibility to an explicit version. | Same-analyzer replay equality test, lab offline replay with no networking and inert kubeconfig helper marker, and schema/clock-edge tests. |
| Integrity checks imply trust or permit hostile files | Check bounded parsing, identity validation, strict schemas, and integrity. Treat captured hashes as corruption detection. Use reviewed retained fields. Bind a local MCP artifact to startup permissions with explicit size and handle limits. | Parser robustness and fuzz tests, sentinel leakage tests, scoped artifact denial and subprocess MCP interoperability. |
| Time-series resampling or workload identity drift creates spurious precision | Measure distinct scrape occurrences, capture window, coverage and freshness. Join by verified cluster/workload/container identities. Suppress sizing when data are sparse, warning-laden, limit-censored or confounded by churn, restarts, VPA or utilization-based HPA. | Deterministic statistics and suppression fixtures and a pinned disposable real Prometheus query. |
| Passive inspection is interpreted as connectivity evidence | Label EndpointSlice, DNS and NetworkPolicy observations as control-plane evidence. The lab may perform fixture-only probes from identified disposable clusters. | Baseline kind smoke, Cilium allow/deny fixture with controls, and NodeLocal DNSCache fixture with pinned upstream manifest and discoverable Pod readiness. |
| HTML hides coverage or consumes live resources | Render shared diagnoses, per-source gaps, confidence and relationships. Keep a static view. Escape evidence and validate explicit navigation links. | Automated offline browser checks and screenshot/visual inspection for layout, filtering, print and inert hostile data. |
| Product tests accidentally exercise user credentials or real clusters | Isolate generated kubeconfig, bind mutations to this invocation's positively identified kind control plane, and fail if that identity changes. Restrict CI to low-privilege pull request contexts. | Harness identity checks, documented cleanup, pinned environments, and separate release evidence. |

After implementation, verify each disposition against the actual contracts and distinguish synthetic exercises, live Kubernetes results, current-head CI, and external review.
